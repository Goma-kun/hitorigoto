# 独り言 / Hitorigoto

英語で独り言を話すと、AIが添削してくれる Chrome 拡張機能です。

- 🎙️ ブラウザの音声認識で、話した英語をそのまま文字起こし
- 🧠 停止すると、AIが「指摘（最大5件）」「修正版（音読用）」「よかった点」を返します
- 💻 **APIキー不要**: Chrome 内蔵AI（Gemini Nano）で端末内で完結
- ✨ 精度を上げたい人は、自分の Gemini APIキーも使えます（任意）
- 🎧 **Gemini APIキーがあれば、録音した音声そのものを Gemini に渡して書き起こしと添削を一度に行います**（v1.1.0〜・設定でオフにできます）。Chrome の音声認識が日本語なまりの英語を別の単語に聞き取り、言っていないことを直される事故が減ります。「発音で伝わらなかった箇所」も別枠で分かります
- 📈 繰り返し出ている癖を記録し、次の練習の前に表示します
- 🔒 端末内AI（テキストのみ）のときは発音の評価をしません（音声がAIに届いていないため。不正確なフィードバックを返さないための設計です）

## 使い方

1. `chrome://extensions` で本拡張機能を読み込む（ストア公開後はストアから）
2. ツールバーのアイコンをクリックしてパネルを開く
3. 初回のみ: 設定から端末内AIを有効化（モデルのダウンロード）
4. 「▶ 開始」を押して、英語で独り言を話す
5. 「■ 停止」を押すと、フィードバックが表示される

## 対応環境（端末内AI）

- Chrome 138 以降
- メモリ 16GB 以上のパソコン推奨（初回に約4GBのモデルをダウンロード）
- 対応していない環境では、Gemini APIキー（任意設定）で利用できます

## 既知の制限と今後の予定

精度はまだ発展途上です。とくに内蔵AI（Gemini Nano）は軽量モデルのため、限界があります。

### 既知の制限

- 指摘の精度には限界があります。気になる場合は、自分の Gemini APIキー（任意設定）の利用をおすすめします
- Chrome の音声認識が固有名詞や日本語由来の言葉を別の英単語に聞き取ることがあります。テキストだけで添削するモード（端末内AI、または音声の送信をオフにした場合）では「聞き取りが怪しい箇所」の検出も完全ではなく、認識ミス由来の箇所を通常の指摘として出してしまうことがあります。実測では指摘 5 件のうち 4 件が認識ミス由来だった回もありました。音声を Gemini に送るモードはこれを減らすためのものです
- 端末内AIでは発音の評価をしません（音声はAIに送っていないため。これは制限ではなく設計です）

### 今後の予定

- 指摘と聞き取り違い検出の精度改善（プロンプト調整を継続します）
- 言い回し・語彙の指摘を「自分専用の表現帳」として自動で溜め、見返す導線
- 練習履歴の要約: 繰り返しの癖をより賢く追跡する機能（v1.1 で予定）

## 開発

```
node test/english_test.mjs
node test/prompt_test.mjs
```

`prompt_test.mjs` は、音声モードのシステム指示がテキスト用から正しく派生できているか（目印が残っているか）を検証します。
`test/audio_e2e.mjs` は Chrome for Testing で本番の拡張を開き、実際の音声を Gemini に流して描画・保存まで通す E2E です（`AUDIO=<webm> ASR="<Chrome の認識テキスト>" node test/audio_e2e.mjs`。要 Gemini API キー）。

`test/harness-*.html` は chrome API をスタブして本番コードを通す検証用ページです（パッケージには含めません）。
